## 🚀 از راه‌اندازی تا اولین فروش

روی VPS لینوکسی تازه، دامنه را به سرور متصل و دستور زیر را اجرا کنید:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/officialdarvish/D_bot/main/install.sh)
```

1. **نصب:** دامنه و SSL، مشخصات تلگرام، ورود وب و PostgreSQL را تنظیم کنید.
2. **تکمیل Setup Wizard:** گزینه‌های کانال و قوانین، مشخصات ربات و پشتیبانی، پیام اصلی و مسیر خصوصی وب را مشخص و **Save and complete setup** را بزنید.
3. **شروع فروش:** پنل‌ها را متصل، پلن‌ها را اضافه و مینی‌اپ را از وب‌پنل فعال کنید.

<details>
<summary><b>⌨️ راه‌اندازی و فرمان‌های سریع</b></summary>

با `dbot` یا `dbot menu` مرکز کنترل را باز کنید. شماره گزینه را وارد کنید یا فرمان مستقیم آن را بزنید:

| منو | فرمان | عملکرد |
| --- | --- | --- |
| ۱ / ۲ | `dbot status` / `dbot logs` | وضعیت کانتینرها / لاگ زنده؛ خروج از لاگ با `Ctrl+C` |
| ۳ / ۴ / ۵ | `dbot restart` / `dbot start` / `dbot stop` | مدیریت سرویس‌ها |
| ۶ | `dbot update` | به‌روزرسانی و ساخت مجدد |
| ۷ | `dbot backup` | بکاپ کامل پروژه با حالت حفاظت ذخیره‌شده |
| ۸ / ۹ | — | مشاهده / ویرایش مقادیر راه‌اندازی |
| ۱۰ / ۱۱ | — / `dbot credentials` | Nginx و SSL / مرکز اطلاعات ورود |
| ۱۳ | `dbot backups` | مدیریت بکاپ‌های ذخیره‌شده |
| ۰ | — | خروج از منو |

فرمان `dbot backup-keys` فهرست کلیدهای اختصاصی ثبت‌شده را خروجی می‌دهد. اطلاعات محرمانه را با `umask 077` در محل امن نگهداری کنید.

</details>

## 🔐 حفاظت بکاپ با انتخاب شما

در **Backup & Restore** یا **Settings** حالت را انتخاب و پیش از ساخت بکاپ ذخیره کنید:

| حالت | بازیابی روی VPS جدید |
| --- | --- |
| عادی | بدون رمزنگاری کامل؛ JSON دیتابیس یا آرشیو پروژه قابل خواندن است. |
| کلید اختصاصی | با کلید بازیابی یا فایل `dbot-recovery-keys.json`. هنگام ذخیره، همه کلیدهای بکاپ ثبت‌شده به مقصد تنظیم‌شده ارسال می‌شوند؛ هر بکاپ ارسالی نیز پیام جداگانه فهرست کلیدها دارد. |
| رمز AES | رمزنگاری AES-256-GCM با scrypt؛ رمز زمان ساخت بکاپ کافی است و همراه فایل ارسال نمی‌شود. |

یک نسخه آفلاین از کلیدها و رمزها نگه دارید. دارنده فایل بکاپ و کلیدهای متناظر می‌تواند آن را بازیابی کند. تغییر حفاظت فقط روی فایل‌های جدید اعمال می‌شود. بکاپ دیتابیس `.dbot`/JSON از وب یا ربات و آرشیو کامل پروژه با ابزار بازیابی آرشیو باز می‌شود. [راهنمای بکاپ](docs/ENCRYPTED_BACKUPS_FA.md).

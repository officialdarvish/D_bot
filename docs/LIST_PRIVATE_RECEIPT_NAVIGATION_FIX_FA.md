# اصلاح مسیردهی فهرست‌ها، پیام خصوصی و رسیدها

این بسته کامل و تجمعی نسخه 1.3.0 است و تغییرات نسخه قبلی را نیز دارد.

## تغییرات

- فهرست خالی تیکت‌ها صفحه مستقل با متن مربوط و یک دکمه بازگشت دارد. فهرست خالی نماینده‌ها و کدهای تخفیف نیز منوی مادر را دوباره نمایش نمی‌دهد.
- پاسخ‌های «فهرست خالی» که قبلاً فقط به شکل اعلان نمایش داده می‌شدند، در صفحه قابل بازگشت نمایش داده می‌شوند. برچسب‌های غیرفعال جای دکمه قابل کلیک نمایش داده نمی‌شوند.
- بروزرسانی، صفحه‌بندی و تغییر زبانه فهرست درخواست‌های تبدیل، تاریخچه تکراری نمی‌سازند. حلقه‌های موجود در تاریخچه ذخیره‌شده نیز هنگام خواندن پاکسازی می‌شوند.
- خطای ورود به گفتگو از پیام خصوصی رفع شده است. کاربر می‌تواند متن یا رسانه بفرستد، گفتگو را ادامه دهد یا با دکمه خاتمه گفتگو آن را پایان دهد. وضعیت یک فرم قبلی به گفتگو منتقل نمی‌شود.
- جزئیات رسید در مسیر مشترک مسیردهی قرار گرفته و فقط یک دکمه بازگشت به فهرست دارد. بازکردن فهرست با دستور /pending_receipts و بروزرسانی همان صفحه نیز تاریخچه اضافی نمی‌سازد.
- مدیر اصلی در جزئیات رسید تاییدنشده دکمه «حذف رسید از فهرست» دارد. حذف پس از تایید انجام می‌شود و صرفاً رسید را از فهرست بررسی بایگانی می‌کند؛ رکورد سفارش، تصویر رسید، سابقه مالی، کیف پول و سرویس حذف یا تغییر نمی‌کنند. بررسی‌کننده تفویض‌شده اجازه این حذف را ندارد. درخواست در حال پردازش یا ارسال سرویس قابل بایگانی نیست.
- پیام نهایی پردازش یک رسید در پس‌زمینه، دکمه‌های رسید دیگری را که مدیر باز کرده تغییر نمی‌دهد.
- پیام پایان گفتگو و پایان حذف رسید، مستقل و با دکمه شروع مجدد ربات نمایش داده می‌شود.

## نصب و بررسی

فایل‌های بسته را در مسیر فعلی پروژه جایگزین کنید و فایل .env و پایگاه داده موجود را حفظ کنید. سپس:

```bash
docker compose up -d --build api bot
```

تغییر ساختار پایگاه داده لازم نیست. نشانه‌های بایگانی در جدول تنظیمات موجود ثبت می‌شوند. خروجی‌های فرانت‌اند همان نسخه قبلی هستند.

مسیرهای اصلی با Dispatcher و FSM واقعی aiogram، پایگاه داده محلی SQLite و انتقال شبیه‌سازی‌شده تلگرام بررسی شده‌اند. بررسی روی تلگرام، پنل و VPS واقعی انجام نشده است. مجموعه آزمون مرتبط با این تغییرات و مسیرهای قبلی: ۳۳۴ آزمون موفق. بررسی کامپایل و کامل‌بودن فایل‌های اجرایی نیز موفق بود.

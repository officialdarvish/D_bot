## فارسی

### تغییرات اصلی
- نمایش نسخه و شماره ساخت، اعلام تغییرات با update.json بدون نیاز به Release برای هر تغییر کوچک، و آپدیت از وب با سرویس میزبان، بکاپ دیتابیس و بررسی سلامت.
- ویزارد اولیه فارسی/انگلیسی، ذخیره پیشرفت، اتصال فرم‌های واقعی پنل و کنترل نمایش/دسترسی قابلیت‌های انتخاب‌شده.
- پشتیبانی NX در ثبت سرور، خرید، نمایندگی، تمدید، مصرف، HWID، تغییر لینک و دریافت فایل‌های اتصال موجود در API پنل.
- اتصال Darvish Bridge در ربات و مینی‌اپ، تنظیمات وب، فاکتور پایدار، مبلغ صحیح ارز و تأیید امضاشده با استعلام دوباره فاکتور.
- استفاده مشترک یک اتصال برای فروش عمومی و نمایندگی؛ مهاجرت تراکنشی گروه‌های سازگار با حفظ شناسه‌های تاریخی، موجودی و دفتر مالی.
- حفظ رسیدها و خلاصه‌سازی پیام تأیید؛ فیلتر Recent Orders برای سفارش دارای رسید.
- پلن قابل انتخاب بر اساس حجم و روز در محدوده مدیر، انتخاب سرور تست، آموزش/قوانین/ویدیو داخل مینی‌اپ و انتخاب اختیاری Xray.
- نگهداری timeout تلگرام در لاگ محلی و گزارش منشأ سورس برای فورک‌های عمومی و کپی‌های ایندکس‌شده دارای نشان پروژه.

### نکات ارتقا و اتصال
- پیش از ارتقا از دیتابیس و تنظیمات بکاپ مستقل بگیرید. نصب‌های قدیمی یک بار به آپدیت دستی نیاز دارند تا سرویس آپدیت میزبان نصب شود؛ پس از آن آپدیت وب در دسترس است.
- گروه‌های دارای تعارض تعرفه، اینباند، نام کاربری یا دریافت‌کننده پرداخت، خودکار ادغام نمی‌شوند و در Servers گزارش می‌شوند.
- نسخه همراه Bridge در integrations/darvish_bridge جداگانه تنظیم می‌شود؛ پشتیبانی پرداخت دیجیتال آن نیازمند فعال‌سازی صریح است. نوع محصول همچنان digital ارسال می‌شود.

### وضعیت بررسی
۶۴ تست مرتبط و ۱۱ تست نسخه همراه Bridge پاس شدند و بیلد Next.js/TypeScript موفق بود. اجرای سراسری ثبت‌شده: ۱۲۱۱ تست موفق، ۱۲ شکست باقی‌مانده از مبنای قبلی و ۳ subtest موفق. آزمون زنده VPS، PostgreSQL، آپدیت/بازیابی Docker و systemd، پنل NX، پرداخت Bridge و مرورگر تعاملی انجام نشده است. جزئیات و فهرست شکست‌ها: docs/VALIDATION_WEB_SETUP.md.

## English

### Highlights
- Version/build display, manifest-based update discovery without a Release for every small change, and a constrained host-side web updater with database backup and health checks.
- Resumable bilingual first-run setup, real configuration forms and shared feature gates.
- NX account lifecycle, reseller operations, usage, HWID, credential rotation and native connection files exposed by the provider API.
- Darvish Bridge bot/Mini App checkout and web settings, durable invoices, integer currency amounts and signed callbacks verified against the remote invoice.
- Shared public/reseller server connections and transactional consolidation of compatible legacy records while preserving financial history and old IDs.
- Preserved receipts, concise approval notices, submitted-receipt Recent Orders, bounded volume/day plans, trial server selection, in-app tutorials/rules/video and optional Xray builds.

### Upgrade and validation notes
Back up the database and configuration before upgrading. Existing installations need one manual bootstrap update to install the host worker. Conflicting legacy groups are retained and reported rather than guessed. The bundled Bridge companion requires separate configuration and explicit digital-payment capability opt-in.

Latest focused tests: 64 passed. Bridge companion: 11 passed. Next.js/TypeScript build passed. Recorded full suite: 1211 passed, 12 remaining baseline failures, 3 subtests passed. Live VPS/PostgreSQL, Docker/systemd update and recovery, NX/Bridge/Telegram delivery and interactive browser validation remain outstanding. See docs/VALIDATION_WEB_SETUP.md and the FA setup/migration guides for details.

# D Bot v1.3.0 — اکانت تست با حجم اعشاری

- سقف یک گیگابایت برای تنظیمات اکانت تست وجود ندارد؛ حجم‌های بیشتر از ۱ گیگ مانند ۲، ۵ و ۱۰ گیگ پذیرفته می‌شوند.
- ورود حجم اعشاری بر حسب گیگابایت در پنل وب و منوی مدیریت ربات پشتیبانی می‌شود؛ مانند `0.1`، `0.2`، `0.5` و `1.5`.
- حجم تست در پنل‌های Sanaei / 3x-ui، PasarGuard و MikroTik با تبدیل دقیق گیگابایت به بایت اعمال می‌شود.
- مشکل تبدیل زودهنگام حجم اعشاری PasarGuard به عدد صحیح (و در نتیجه صفر/نامحدود شدن اشتراک‌های زیر ۱ گیگ) اصلاح شد.
- اعتبارسنجی ورودی‌های نامعتبر، منفی، صفر و مقادیر غیرمتناهی در سمت سرور و مدیریت تلگرام اعمال می‌شود.
- تنظیمات و اکانت‌های قبلی بدون نیاز به مهاجرت پایگاه داده باقی می‌مانند.

**توجه:** D Bot همانند نسخه‌های قبلی از ضریب `1024³` بایت برای هر گیگابایت در محاسبات پنل استفاده می‌کند. بنابراین `0.1 GB` حدود `102.4 MiB` است؛ برای نمایش کاربر به شکل تقریبی ۱۰۰ مگابایت بیان شده است.

**نصب:** آرشیو کامل پروژه را جایگزین سورس فعلی کنید و طبق راهنمای نصب، سرویس Docker را بازسازی و مجدداً اجرا کنید.

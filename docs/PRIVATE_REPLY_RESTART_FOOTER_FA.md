# دکمه‌های پس از ارسال پاسخ

پس از ارسال موفق پاسخ کاربر به پیام خصوصی مدیر، فقط این سه دکمه نمایش داده می‌شوند:

- پاسخ به پیام
- خاتمه گفتگو
- شروع مجدد ربات

بازگشت به پیام اصلی مدیر از این صفحه حذف شده است. شروع مجدد، وضعیت گفتگو را پاک می‌کند و منوی اصلی را در پیام جدید باز می‌کند. پاسخ مجدد و خاتمه گفتگو فعال باقی می‌مانند. مسیر بازگشت سایر منوها تغییر نکرده است.

۳۹ آزمون محلی مرتبط با گفتگو و مسیردهی موفق بود. اتصال به تلگرام واقعی انجام نشده است. این بسته کامل و تجمعی است و اصلاحات قبلی انقضا و هشدار حجم را نیز دارد.

فایل .env و پایگاه داده را هنگام جایگزینی حفظ کنید و سپس اجرا کنید:

```bash
docker compose up -d --build api bot
```

# گزارش حذف اکانت تست برای مدیر

- حذف تست از ربات و مینی‌اپ از گزارش مشترک حذف سرویس استفاده می‌کند و با عنوان «گزارش حذف اکانت تست» ارسال می‌شود.
- نام مالک، یوزرنیم و آیدی عددی، نام کانفیگ، سرور، حجم کل و مانده و تاریخ انقضا در گزارش وجود دارد.
- اگر حذف از پنل در صف تلاش مجدد باشد، وضعیت صف به‌جای اعلام حذف قطعی نمایش داده می‌شود.
- تست از سابقه دریافت تست تشخیص داده می‌شود؛ نام سیستمی تست نیز برای موارد قدیمی و ساخت چندسروری پشتیبانی می‌شود.
- مسیر مینی‌اپ، گزارش مدیر را با اتصال واقعی ارسال می‌کند تا حالت بی‌صدای رابط کاربر، گزارش حذف تست خود مدیر را مسدود نکند.
- گزارش پس از ثبت حذف در دیتابیس ارسال می‌شود. در صورت شکست ارسال، سابقه گزارش در صف می‌ماند و مجدداً تلاش می‌شود؛ اجرای معمول مجدد صف، گزارش موفق را تکرار نمی‌کند.
- حذف اکانت تست سهمیه دریافت تست کاربر را آزاد نمی‌کند.

اعتبارسنجی اولیه: ۱۷ تست محلی حذف تست و عمومی، سنایی و پاسارگارد، ربات و مینی‌اپ، قطعی پنل، قطعی تلگرام، گزارش حذف تست مدیر و جلوگیری از تکرار موفق بودند. تلگرام و پنل واقعی در این محیط آزمایش نشده‌اند.

برای نصب، با حفظ فایل محیط و دیتابیس و پس از جایگزینی سورس اجرا کنید:

```sh
docker compose build api bot && docker compose up -d --no-build api bot
```

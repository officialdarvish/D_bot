# اصلاح بررسی عضویت هنگام اختلال ارتباط تلگرام

لاگ ارسالی مربوط به قطع اتصال به api.telegram.org:443 هنگام GetChatMember است.
از این لاگ نمی‌توان علت دقیق قطع اتصال در شبکه، پروکسی یا سمت مقصد را تعیین کرد.

- بررسی عضویت با حداکثر دو تلاش و مهلت چهار ثانیه برای هر تلاش انجام می‌شود.
- فقط خطای شبکه و اتمام مهلت باعث تلاش مجدد می‌شود؛ درخواست‌های پرداخت، ساخت اکانت و ارسال پیام تکرار نمی‌شوند.
- هنگام اختلال، پیام «عضویت شما هنوز بررسی نشده است» همراه دکمه بررسی مجدد نمایش داده می‌شود؛ عضویت اجباری دور زده نمی‌شود.
- خطاهای دسترسی کانال و تنظیمات ربات جداگانه باقی می‌مانند.
- پاسخ اولیه دکمه بررسی عضویت پیش از درخواست شبکه ارسال می‌شود.
- وضعیت restricted همراه is_member=true به‌درستی عضو محسوب می‌شود.

این اصلاح تاب‌آوری مسیر بررسی عضویت را افزایش می‌دهد و اختلال دائمی اتصال VPS به تلگرام را برطرف نمی‌کند. در صورت تکرار، تست اتصال تلگرام و تنظیمات پروکسی ربات روی VPS بررسی شود.

برای نصب، فایل‌های نسخه جدید را جایگزین و با حفظ فایل محیط و دیتابیس اجرا کنید:

```sh
docker compose up -d --build api bot
```

تست‌ها با شبیه‌سازی قطع اتصال، timeout، درخواست معلق، لغو پردازش، وضعیت‌های عضویت و خطاهای دسترسی اجرا می‌شوند؛ اتصال واقعی VPS در این محیط قابل بررسی نیست.

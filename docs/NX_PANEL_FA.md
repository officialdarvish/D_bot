# اتصال NX Panel به D BOT

در Servers نوع NX Panel را انتخاب کنید. آدرس دقیق پنل همراه مسیر خصوصی و API Token پنل را وارد کنید. لینک اشتراک صادرشده توسط NX اولویت دارد؛ پایه اشتراک اختیاری فقط برای پاسخ‌های فاقد subUrl استفاده می‌شود. در NX باید حداقل یک template در دسترس توکن باشد.

Templateها به گزینه‌های پلن متصل می‌شوند. یک سرور می‌تواند scope=all داشته باشد و برای فروش عمومی و ساخت سرویس نماینده استفاده شود. ساخت حساب، تمدید، افزایش حجم/روز، فعال/غیرفعال‌سازی، حذف، آمار مصرف، HWID و تغییر مشخصات اتصال از API نسخه v1 استفاده می‌کنند. فایل‌های OpenVPN، OpenConnect و WireGuard از مسیر app-configs در ربات و مینی‌اپ قابل دریافت‌اند، اگر خود NX برای کاربر فایل برگرداند.

ساخت مبهم بعد از قطع ارتباط بدون تکرار POST بررسی می‌شود. فقط حساب دارای نشان اختصاصی همان درخواست و سهمیه منطبق قابل بازیابی است. ویرایش با PATCH و updatedAt انجام می‌شود؛ رقابت ویرایش به خطا می‌انجامد و اطلاعات سایر اپراتورها بی‌صدا بازنویسی نمی‌شود.

فروش حساب مدیریتی پنل PasarGuard اختصاصی همان پنل است. نمایندگی NX در این پیاده‌سازی از نوع حساب‌های مشترک D BOT با حجم یا PAYG است و به معنی ساخت حساب مدیر NX نیست.

قرارداد API: https://docs.nx-panel.org/reference/api
سورس عمومی نصب و مستندات: https://github.com/nx-panel/panel

تست‌ها با پاسخ‌های شبیه‌سازی‌شده API و مسیر واقعی سفارش انجام شده‌اند. اتصال به NX واقعی و تحویل فایل روی دستگاه کاربر هنوز نیازمند اعتبارسنجی است.

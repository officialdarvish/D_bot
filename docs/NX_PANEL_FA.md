# اتصال NX Panel به D BOT

در Servers نوع NX Panel را انتخاب کنید. آدرس دقیق پنل همراه مسیر خصوصی و API Token پنل را وارد کنید. لینک اشتراک صادرشده توسط NX اولویت دارد؛ پایه اشتراک اختیاری فقط برای پاسخ‌های فاقد subUrl استفاده می‌شود. در NX باید حداقل یک template در دسترس توکن باشد.

Templateها به گزینه‌های پلن متصل می‌شوند. یک سرور می‌تواند scope=all داشته باشد و برای فروش عمومی و ساخت سرویس نماینده استفاده شود. ساخت حساب، تمدید، افزایش حجم/روز، فعال/غیرفعال‌سازی، حذف، آمار مصرف، HWID و تغییر مشخصات اتصال از API نسخه v1 استفاده می‌کنند. فایل‌های OpenVPN، OpenConnect و WireGuard از مسیر app-configs در ربات و مینی‌اپ قابل دریافت‌اند، اگر خود NX برای کاربر فایل برگرداند.

ساخت مبهم بعد از قطع ارتباط بدون تکرار POST بررسی می‌شود. فقط حساب دارای نشان اختصاصی همان درخواست و سهمیه منطبق قابل بازیابی است. ویرایش با PATCH و updatedAt انجام می‌شود؛ رقابت ویرایش به خطا می‌انجامد و اطلاعات سایر اپراتورها بی‌صدا بازنویسی نمی‌شود.

فروش حساب مدیریتی پنل PasarGuard اختصاصی همان پنل است. نمایندگی NX در این پیاده‌سازی از نوع حساب‌های مشترک D BOT با حجم یا PAYG است و به معنی ساخت حساب مدیر NX نیست.

قرارداد API: https://docs.nx-panel.org/reference/api
سورس عمومی نصب و مستندات: https://github.com/nx-panel/panel

تست‌ها با پاسخ‌های شبیه‌سازی‌شده API و مسیر واقعی سفارش انجام شده‌اند. اتصال به NX واقعی و تحویل فایل روی دستگاه کاربر هنوز نیازمند اعتبارسنجی است.


## تنظیم آدرس پنل و رفع خطای 404

مسیر خصوصی پنل باید در URL درخواست حفظ شود. در Servers و ویزارد می‌توانید آدرس را به یکی از این دو روش وارد کنید:

| Panel URL / Origin | Panel Web Path |
| --- | --- |
| `https://panel.example.com:28431` | `/secret-path/` |
| `https://panel.example.com:28431/secret-path/` | `/` |

هر دو روش به `https://panel.example.com:28431/secret-path/api/v1/templates` متصل می‌شوند. اگر آدرس با `/api/v1`، `/api` یا `/login` تمام شود، این پسوند حذف می‌شود تا مسیر API دوبار اضافه نشود. دامنه و پورت باید متعلق به وب‌پنل NX باشند، نه آدرس نود یا اشتراک کاربران. در تست و ویرایش، مسیر خصوصی حفظ می‌شود؛ توکن قبلی با خالی‌گذاشتن فیلد توکن هنگام ویرایش تغییر نمی‌کند.

اگر همچنان 404 دریافت شد، درستی آدرس، پورت و مسیر خصوصی و پشتیبانی نسخه NX از API پایدار `/api/v1` را بررسی کنید. خطای 401/403 معمولاً به اعتبار یا مجوز توکن مربوط است. پاسخ HTML یا redirect به صفحه ورود نیز به‌عنوان اتصال موفق پذیرفته نمی‌شود. مسیرهای تغییر حساب خودکار به API دیگری تغییر داده یا دوباره اجرا نمی‌شوند.

مرجع رسمی: https://docs.nx-panel.org/reference/api — بخش Before you call it و Templates.


### خطای Unexpected token '<' در ویزارد

این پیام می‌تواند از خواندن صفحه HTML به‌جای پاسخ JSON وب‌پنل D BOT باشد و به‌تنهایی به معنی ردشدن اتصال NX نیست. بیلد ۱۹ درخواست ذخیره ویزارد را با پاسخ JSON هماهنگ می‌کند و نشست منقضی یا پاسخ غیر JSON را بدون تکرار خودکار درخواست مدیریت می‌کند. اگر این خطا در نسخه قبلی پس از افزودن سرور ظاهر شد، پیش از افزودن دوباره، فهرست سرورها را بررسی کنید؛ ذخیره قبلی ممکن است موفق شده باشد.

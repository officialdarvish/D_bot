# اصلاح کنترل نمایش نمایندگی

علت: تنظیم `button_reseller_menu_enabled` فقط برای مدیر و نماینده فعال خوانده می‌شد، اما کاربر عادی با تنظیم مستقل `button_reseller_request_enabled` دکمه درخواست نمایندگی را می‌دید.

اصلاح: کلید منوی نمایندگی اکنون کنترل اصلی نمایش هر دو دکمه است. وقتی خاموش باشد، دکمه نمایندگی از منوی تازه همه نقش‌ها حذف می‌شود و callback ورودی نمایندگی از پیام قدیمی برای کاربر عادی و نماینده غیرفعال است. تنظیم مستقل درخواست همچنان می‌تواند فقط درخواست‌های جدید را مخفی کند؛ روشن‌کردن کلید اصلی، مقدار مستقل درخواست را تغییر نمی‌دهد.

محدوده: کنترل نمایش/ورود منوی ربات است. حساب‌های موجود، موجودی، خدمات و محاسبه مالی تغییر نمی‌کنند. تنظیمات مستقل مینی‌اپ و فروش پنل نمایندگی همان رفتار قبلی را دارند. پیام‌های قدیمی تلگرام خودکار برای همه کاربران ویرایش نمی‌شوند؛ دکمه قدیمی کار نمی‌کند و با /start یا شروع مجدد، منوی جدید ساخته می‌شود.

اعتبارسنجی: 56 تست مرتبط پاس شد؛ شامل 15 تست جدید برای وضعیت روشن/خاموش هر دو کلید در سه نقش، کلیک پیام قدیمی و اعمال تغییر با کش گرم. تست‌ها محلی با دیتابیس آزمایشی و ارتباط شبیه‌سازی‌شده هستند. نصب یا تست روی تلگرام واقعی کاربر انجام نشده است.

این بسته کامل بر مبنای آخرین اصلاح خرید کیف پول پاسارگارد نسخه 1.3.0 است و اصلاحات کیف پول و حجم تست را حفظ می‌کند. پس از جایگزینی سورس، api و bot را با روش نصب فعلی بازسازی/راه‌اندازی کنید؛ migration جدید لازم نیست.

# اصلاحات مینی‌اپ و ارسال خطا — 1.3.0

- تبدیل تعرفه: انتخاب دسته و پلن مقصد، پیش‌نمایش حجم، تأیید، پیگیری و دریافت کانفیگ جدید داخل مینی‌اپ انجام می‌شود. ادامه مراحل به چت ربات منتقل نمی‌شود.
- پیش‌نمایش تبدیل پنج دقیقه اعتبار دارد. مالکیت، مصرف، نرخ‌ها و انقضا هنگام اجرا دوباره بررسی می‌شوند. هر کانفیگ فقط یک بار تبدیل می‌شود؛ عملیات نامشخص برای بررسی مدیر نگه داشته می‌شود.
- دکمه بررسی وضعیت سفارش در مرحله ارسال رسید نمایش داده نمی‌شود؛ دریافت وضعیت خودکار ادامه دارد.
- پاسارگارد: پاسخ معتبر عملیات تغییر لینک استفاده می‌شود؛ خواندن اطلاعات قدیمی باعث اجرای دوباره درخواست تغییر لینک نمی‌شود. ریست HWID از همان مسیر تأییدشده استفاده می‌کند. شناسه کاربر و گروه‌ها حفظ و بررسی می‌شوند.
- در «بکاپ و بازیابی → ارسال لاگ خطا» می‌توان مقصد بکاپ، مقصد اختصاصی یا غیرفعال را انتخاب کرد. مقصد اختصاصی می‌تواند کانال، گروه یا چت خصوصی با ربات باشد و از ربات فعلی یا توکن جداگانه استفاده کند.
- برای کانال و گروه، ربات ارسال‌کننده باید مدیر باشد. برای چت خصوصی، ابتدا ربات را استارت کنید و آیدی عددی خود را وارد کنید. ارسال مستقیم از یک ربات به ربات دیگر ممکن نیست.
- تست مقصد تنظیمات را فعال نمی‌کند؛ پس از تست ذخیره کنید. خالی گذاشتن توکن، توکن قبلی را حفظ می‌کند. توکن رمز‌شده ذخیره و همراه سایر اطلاعات محرمانه بکاپ برای بازیابی روی نصب جدید آماده می‌شود.

## نصب تغییرات

فایل کامل را در پوشه پروژه جایگزین و سرویس‌های ربات و API را بازسازی کنید:

```bash
docker compose up -d --build api bot
```

دیتابیس و فایل محیط فعلی را نگه دارید. این نسخه نیازی به حذف یا بازنشانی دیتابیس ندارد.

## اعتبارسنجی

مسیرهای تغییر یافته با تست‌های خودکار، ساخت Next.js و بررسی مرورگری موبایل و دسکتاپ آزمایش شده‌اند. دسترسی به پنل عملیاتی و VPS کاربر برای آزمون زنده وجود نداشته است.

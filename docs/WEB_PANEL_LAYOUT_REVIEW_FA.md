# بررسی و اصلاح رابط وب‌پنل D Bot 1.3.0

این بسته کامل و تجمعی است و اصلاحات قبلی ربات، گفتگو، رسید، انقضا و هشدار حجم را حفظ می‌کند.

## ایرادهای پیدا‌شده و اصلاحات

| مورد | اصلاح |
| --- | --- |
| متغیرهای تعریف‌نشده رنگ در فرم‌ها و بخش اتصال | تعریف رنگ حاشیه، رنگ تأکیدی و زمینه ورودی‌ها در محدوده وب‌پنل با پالت موجود |
| احتمال خروج متن‌های بلند، عنوان و مقادیر از کارت | اجازه شکستن متن و کاهش عرض فرزندان flex/grid؛ شکستن ردیف عنوان‌ها و دکمه‌ها |
| فشردگی نوار جستجو و دکمه‌ها در موبایل | عرض انعطاف‌پذیر جستجو، حذف راهنمای میانبر در موبایل، چینش منعطف دکمه‌ها |
| نبود فوکوس مشخص برای بعضی کنترل‌ها | فوکوس قابل مشاهده برای لینک، دکمه، ورودی، چک‌باکس و جدول |
| فوکوس‌پذیری منوی بسته موبایل | مخفی‌شدن واقعی منو در حالت بسته؛ اندازه آیکن و عرض ریل دسکتاپ حفظ شده است |
| پنجره ویرایش بدون مدیریت مشترک کیبورد | انتقال فوکوس به فرم، نگه‌داشتن Tab در پنجره، Escape، جلوگیری از اسکرول صفحه پشت و بازگرداندن فوکوس پس از بستن |
| امکان تکرار کلیک ذخیره فرم | وضعیت ذخیره در حال انجام، غیرفعال‌شدن ذخیره/تست/بستن حین ذخیره و انتظار برای پایان درخواست |
| برچسب‌های تو‌در‌تو و نامعتبر در فرم چندانتخابی | تبدیل ظرف کنترل‌های گروهی به گروه مستقل با نام قابل دسترس |
| بعضی فهرست‌های کارت در حالت خالی یا جستجوی بی‌نتیجه، صفحه سفید داشتند | پیام راهنمای مشخص برای سرورها، دسته‌ها، پلن‌ها، پرداخت‌ها، تخفیف‌ها، نماینده‌ها و پروفایل‌ها |
| راهنمای میانبر جستجو بدون عملکرد | فعال‌شدن Ctrl+K و Cmd+K؛ در پنجره باز، فوکوس از فرم خارج نمی‌شود |
| ادامه درخواست‌های قدیمی پس از تغییر صفحه یا جستجو | لغو درخواست با AbortController و جلوگیری از نمایش خطا یا نتیجه درخواست لغوشده |
| پیمایش جدول فقط با ماوس | امکان فوکوس جدول و پیمایش آن با کیبورد، همراه نام قابل دسترس |

متن‌های جدید فارسی و انگلیسی دارند. ورودی‌های نشانی، ایمیل و رمز جهت چپ‌به‌راست دارند. در موبایل، اندازه متن ورودی برای جلوگیری از بزرگ‌نمایی ناخواسته و ارتفاع پنجره برای فضای قابل مشاهده تنظیم شده است.

## دامنه بررسی و نتیجه اعتبارسنجی

کد پوسته مشترک، منو، فرم‌ها، کارت‌ها، جدول‌ها و مسیرهای داشبورد، سرورها، دسته‌ها، پلن‌ها، کاربران، نمایندگی، فروش پنل، پرداخت‌ها، تخفیف‌ها، سرویس‌ها، تست، پروفایل OpenVPN، اتصال، بکاپ، سفارشی‌سازی، مینی‌اپ و تنظیمات بررسی شد. تغییرات مشترک روی صفحات مدیریت اعمال می‌شوند؛ منطق مالی یا ساخت سرویس تغییر نکرده است.

- `npm run lint` شامل بررسی TypeScript موفق بود.
- `npm run build` موفق بود و ۲۴ صفحه HTML خروجی ساخت.
- وجود فایل‌های Next.js ارجاع‌شده در تمام HTMLهای خروجی بررسی شد؛ فایل مفقودی نداشتند.
- ۱۷ آزمون مرتبط با وب، تنظیمات، ارائه فایل‌های استاتیک و کامل‌بودن سورس موفق بود.
- خروجی‌های frontend/out و frontend_out دوباره ساخته و یکسان‌سازی شدند؛ فایل‌های قدیمی خروجی در بسته جدید باقی نمی‌مانند.

**محدودیت بررسی:** مرورگر این محیط به سرور محلی پیش‌نمایش وصل نشد و Chromium محلی نیز قابل دریافت نبود. بنابراین این گزارش، تأیید تصویری و تعاملی همه صفحات روی موبایل و مرورگر واقعی نیست. کیفیت نهایی رندر و رفتار فوکوس باید پس از نصب در مرورگر واقعی نیز بررسی شود.

## اعمال نسخه

فایل‌های بسته را در مسیر پروژه جایگزین کنید و .env و پایگاه داده را حفظ کنید. سپس اجرا کنید:

```bash
docker compose up -d --build api bot
```

ساختار پایگاه داده در این اصلاحات وب تغییر نکرده است.

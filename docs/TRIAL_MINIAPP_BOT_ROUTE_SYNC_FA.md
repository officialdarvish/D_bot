# یکپارچه‌سازی مسیر اکانت تست ربات و مینی‌اپ

- کلید فعال‌بودن تست، نمایش دکمه و کلید سفارشی دکمه در هر دو مسیر رعایت می‌شود. دکمه قدیمی ربات هم امکان دورزدن این تنظیمات را ندارد.
- عنوان سفارشی دکمه ربات در خانه مینی‌اپ نمایش داده می‌شود.
- حجم، مدت و سرورهای تست از تنظیمات مشترک خوانده می‌شوند. مقدار نامعتبر یا کمتر از یک روز در نمایش و ساخت، یکسان به یک روز تبدیل می‌شود.
- سهمیه یک‌بار مصرف کاربر عادی در هر دو مسیر مشترک است. مدیر پس از پایان ساخت می‌تواند تست جدید بگیرد؛ درخواست در حال پردازش دوباره ایجاد نمی‌شود.
- تست‌های دریافت‌شده از ربات و مینی‌اپ در صفحه تست قابل دریافت‌اند. کانفیگ حذف‌شده از لیست مالک دوباره در نتایج نمایش داده نمی‌شود.
- بازگشت از جزئیات، ابتدا به صفحه تست و سپس به خانه می‌رود. دکمه داخل صفحه و دکمه بازگشت تلگرام این ترتیب را رعایت می‌کنند.
- مراحل خرید و پرداخت برای جزئیات اکانت تست نمایش داده نمی‌شوند.
- وضعیت پس از پایان ساخت، بروزرسانی دستی، بازگشت به برنامه و هنگام بازماندن صفحه همگام می‌شود. پاسخ دیرهنگام درخواست قبلی جای وضعیت جدید را نمی‌گیرد.
- نتیجه نهایی در ربات با دکمه شروع مجدد ارسال می‌شود؛ نمایش خودکار منوی اصلی پس از تحویل حذف شده است.

## بررسی انجام‌شده

۱۰۶ تست پایتون و ۹ تست جاوااسکریپت موفق بودند. بررسی TypeScript، ساخت خروجی وب و بررسی فایل‌های لازم اجرا شد. همچنین خود مؤلفه مینی‌اپ با API و محیط تلگرام شبیه‌سازی‌شده از خانه تا تست، پردازش، تحویل، جزئیات و بازگشت آزمایش شد. اتصال واقعی تلگرام و پنل روی VPS در این محیط آزمایش نشده است.

## بروزرسانی

نسخه کامل شامل اصلاحات قبلی است. فایل‌های محیط و دیتابیس فعلی را حفظ کنید و پس از جایگزینی سورس اجرا کنید:

```sh
docker compose up -d --build api bot
```

پس از بروزرسانی، مینی‌اپ را کاملاً ببندید و از داخل تلگرام دوباره باز کنید.

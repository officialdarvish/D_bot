# اصلاح رابط مدیریت و پاک‌سازی دیسک

- بخش قالب تحویل سرویس و مدیریت مالی نمایندگی با زبان رابط فارسی/انگلیسی و جهت مناسب نمایش داده می‌شوند. متن اختصاصی پیام‌ها و قالب‌های ذخیره‌شده تغییر نمی‌کند.
- حفاظت بکاپ فقط در صفحه بکاپ نمایش داده می‌شود؛ از Settings حذف شده است.
- تنظیمات مالی سرور فقط برای Reseller نمایش داده می‌شوند. تعرفه PAYG تنها هنگام انتخاب PAYG نمایش داده و ارسال می‌شود.
- راهنمای توکن PasarGuard استفاده از توکن را برای بهبود سرعت و عملکرد توصیه می‌کند. ورود با نام کاربری و رمز همچنان پشتیبانی می‌شود.
- تغییر موجودی و دلیل تغییر کیف پول فقط در ویرایش نمایندگی PAYG نمایش داده می‌شود.

## پاک‌سازی فایل‌های موقت

دکمه زیر Disk Usage ابتدا تعداد و حجم فایل‌های قابل حذف را محاسبه می‌کند و بعد از تأیید مدیر، آن‌ها را حذف می‌کند. تنها فایل‌های موقت متعلق به D Bot در پوشه اختصاصی `/tmp/dbot-artifacts` با عمر بیش از ۷ روز قابل حذف هستند. فایل‌های جدید، فایل‌های ناشناس، پیوندها و پوشه‌های تو در تو حذف نمی‌شوند. درخواست دارای احراز هویت و بررسی CSRF است.

**هیچ جدول، رکورد یا داده‌ای در دیتابیس پاک یا تغییر داده نمی‌شود.** بکاپ‌های ذخیره‌شده خارج از پوشه موقت، کلیدهای اصلی، فایل‌های تنظیمات، فایل‌های پروژه و کانتینرهای دیتابیس دست‌نخورده باقی می‌مانند. فایل‌های موقت تحویل بکاپ، QR، گزارش و پروفایل که پس از ارسال موفق معمولاً خودکار حذف می‌شوند، از این پس در پوشه مشترک اختصاصی API و ربات ایجاد می‌شوند؛ دکمه باقی‌مانده‌های قدیمی آن‌ها را پاک می‌کند.

رسیدهای این نسخه با شناسه فایل تلگرام نگهداری می‌شوند و هنگام مشاهده در حافظه خوانده می‌شوند؛ دکمه رسیدها یا سوابق مالی را حذف نمی‌کند. این ابزار فایل‌های قدیمی ناشناس در `/tmp`، لاگ‌های میزبان، ایمیج‌های Docker یا بکاپ‌های دستی را حذف نمی‌کند؛ بنابراین میزان آزادسازی به فایل‌های موقت موجود بستگی دارد. اندازه نمایش‌داده‌شده مجموع اندازه منطقی فایل‌های حذف‌شده است؛ فضای واقعی آزادشده می‌تواند به فایل‌سیستم وابسته باشد.

برای جلوگیری از رشد نامحدود لاگ، کانتینرهای API و ربات هرکدام حداکثر سه فایل لاگ ۱۰ مگابایتی نگه می‌دارند. این محدودیت پس از بازسازی کانتینرها اعمال می‌شود.

## اعمال به‌روزرسانی

```bash
docker compose up -d --build api bot
```

این تغییر به مهاجرت یا حذف دیتابیس نیاز ندارد. وضعیت فضای دیسک پس از پاک‌سازی دوباره خوانده می‌شود.

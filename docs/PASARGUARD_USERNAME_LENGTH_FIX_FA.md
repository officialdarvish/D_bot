# اصلاح خطای 422 نام کاربری پاسارگارد

لاگ ارسالی برای سفارش 33 خطای زیر را در POST /api/user نشان می‌دهد:

```text
422: username: Username only can be 3 to 128 characters.
```

خطا مربوط به رد درخواست ساخت توسط اعتبارسنجی نام است، نه ارسال کانفیگ در تلگرام. ربات قبلاً نام‌های یک و دو کاراکتری را معتبر می‌دانست، در حالی که پاسارگارد حداقل سه کاراکتر می‌خواهد. نام واقعی در این لاگ درج نشده است؛ با توجه به سقف 32 کاراکتری ورودی ربات، نام کوتاه مسیر قابل بازتولید این ناسازگاری است.

## اصلاحات

- خرید عمومی ربات و مینی‌اپ: نام پاسارگارد با کمتر از سه کاراکتر پیش از پرداخت رد و پیام فارسی راهنما نمایش داده می‌شود. نام‌های سنایی همچنان سیاست قبلی را دارند.
- نمایندگی ربات و ساخت مستقیم نمایندگی در مینی‌اپ: همین شرط پیش از شروع ساخت اعمال می‌شود.
- آداپتر پاسارگارد: پیش از هر درخواست ساخت، بازه طول 3 تا 128 کنترل می‌شود. محدودیت ورودی ربات همچنان 32 کاراکتر است.
- سفارش‌های قبلاً ثبت/پرداخت‌شده با نام کوتاه: سازنده سرویس از شمارنده پایدار نام تکراری برای ساخت نام معتبر و آزاد استفاده می‌کند؛ مثال ab به ab_000001 تبدیل می‌شود. وجود نام تولیدشده نیز بررسی می‌شود تا اکانت دیگری به سفارش وصل نشود. در نمایندگی، همان شمارنده مستقل چهاررقمی قبلی استفاده می‌شود.
- نام نهایی در سرویس و تحویل ذخیره می‌شود؛ تکرار همان کلید خرید، پرداخت یا ساخت را تکرار نمی‌کند.

## سفارش 33

بعد از به‌روزرسانی api و bot، از دکمه تلاش مجدد خرید/ساخت در همان سفارش استفاده کنید. برای این خطای مشخص 422 اعتبارسنجی، درخواست ساخت رد شده است. کاربر نباید خرید تازه یا پرداخت دوباره انجام دهد. این بسته خودِ سفارش 33 یا دیتابیس عملیاتی را تغییر نداده است.

## اعتبارسنجی و نصب

128 تست مرتبط پاس شد. تست‌های جدید شامل نام‌های 1، 2، 3 و 32 کاراکتری، رد پیش از API، جلوگیری از کسر کیف پول برای نام کوتاه، تولید نام یکتا برای سفارش قدیمی، تطبیق نام نهایی و یک‌بار پرداخت/ساخت هستند. APIهای بیرونی شبیه‌سازی شده‌اند و تست روی پنل واقعی انجام نشده است.

بسته بر مبنای آخرین نسخه تنظیمات وب است و اصلاحات پیشین کیف پول، حجم تست، منوی نمایندگی و خروجی آماده وب را حفظ می‌کند. فایل .env و دیتابیس را حفظ و سرویس‌های api و bot را با روش نصب فعلی بازسازی/راه‌اندازی کنید. migration جدید لازم نیست.
